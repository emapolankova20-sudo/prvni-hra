# prvni-hra
# POSLEDNÍ POLIBEK 🖤

## 1. Krátký popis
Poslední polibek je textová hororová hra vytvořená v Pythonu. Hlavní hrdinka se setká se záhadným klukem jménem Alex a postupně odhaluje jeho temnou minulost. Hráč svými rozhodnutími ovlivňuje průběh příběhu a jeho konec.

## 2. Jak hru spustit
1. Stáhni si soubor s názvem `main.py`.
2. Otevři ho v programu, který podporuje Python 3.
3. Klikni na tlačítko Run.
4. Hra se spustí v konzoli.

## 3. Jak se hra ovládá
- Hráč vybírá z nabízených možností pomocí čísel.
- Zvolenou možnost potvrdí klávesou Enter.
- Během hry může sbírat předměty do inventáře.
- Podle svých rozhodnutí se dostane k jednomu z několika konců.
